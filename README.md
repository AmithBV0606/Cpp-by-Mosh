### Introduction to C++ :

C++ is a high-level, general-purpose programming language known for its high performance, speed, and low-level memory management. Developed by Bjarne Stroustrup as an extension of C, it is widely used in operating systems, game development, and high-frequency trading.

**NOTE** : Every 3 years there's a new C++ versions.

#### C++ STL (Standard Template Library) :

STL is a collection of pre-written C++ code, that provides functionality that is required by many applications.

Examples are data structures like "list" & "Map". For algorithms like searching and sorting data.
